# ⏰ Alarm Clock

🪧 **Live Demo**: [Click here to try it out](https://github.com/Kunal-0821/Alarm-clock)

## 📌 About the Project

This is a browser-based **Alarm Clock** application built with **HTML, CSS, and JavaScript**. It allows you to set alarms for any desired time directly in your web browser with a clean and user-friendly interface.

### ✨ Key Features

* 🕒 **Set custom alarms** for any time of the day.
* 💾 **Uses local storage** to persist alarms — your set alarms remain saved even if you close or refresh the browser.
* 🔁 **Session memory** — when you revisit the page, it remembers the last alarm you set and its time.
* 📱 **Responsive design** — works well on both desktop and mobile devices.

### 🛠 Technologies Used

* **HTML5** – for structure
* **CSS3** – for styling
* **JavaScript (ES6)** – for interactivity and alarm logic
* **LocalStorage API** – to store alarms persistently in the browser

## 🚀 Getting Started

To use the alarm clock locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Kunal-0821/Alarm-clock.git
   ```
2. Open `index.html` in your browser.
3. Set an alarm and you're all set!
